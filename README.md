# 小明 AI Tips · xiaoming-ai-tips

AI 工具使用技巧与提示词分享。持续更新，欢迎 Star 与 PR。

## 自我介绍

我是小明，日常折腾各类 AI 工具：写作、编程、绘图、办公自动化。

这个仓库是我的公开笔记本，把用得上手的提示词、踩过的坑、跑通的流程都用大白话记下来，不堆术语，复制就能用。

GitHub：[@wangge-dev](https://github.com/wangge-dev)

## 仓库说明

仓库分三块内容，按用途分类：

| 目录 | 放什么 | 适合谁 |
| --- | --- | --- |
| `prompts/` | 可直接复制的提示词模板，附使用说明和效果示例 | 想立刻上手的人 |
| `tutorials/` | 图文教程，讲清一个工具从装到用的完整步骤 | 刚接触 AI 工具的人 |
| `skills/` | 可复用的技能包，把一套流程封装成固定能力 | 想把重复工作自动化的人 |

几点约定：

- 所有提示词都经过实际使用，能直接粘贴到对话框里跑。
- 效果受模型版本影响，模板里注明了适用的模型和时间。
- 内容按需更新，不做版本号管理，看提交记录即可。
