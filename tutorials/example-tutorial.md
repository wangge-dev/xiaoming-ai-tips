# 从零上手 AI 工具

以 AI 编程助手为例，讲清从安装到跑通第一个任务的完整流程。其他工具思路一样。

## 一、准备

需要三样东西：

1. **一个客户端**。命令行工具或桌面应用都行，看习惯。
2. **一个 API Key**。在服务商后台申请，按量付费，不一定要订阅包月。
3. **一个空文件夹**。给它一个能随便改的目录，不要直接在重要项目上试。

API Key 申请下来后先放好，后面配置要用。Key 等于密码，不要提交到公开仓库。

## 二、安装

命令行工具通常一条命令装完：

```bash
npm install -g @anthropic-ai/claude-code
```

装完输入 `claude --version`，能打印版本号就说明装好了。

桌面应用更简单，官网下载安装包，下一步到底。

## 三、配置

把 Key 写进环境变量，工具启动时会自动读：

```bash
# macOS / Linux
export ANTHROPIC_API_KEY="sk-ant-xxxx"

# Windows PowerShell
$env:ANTHROPIC_API_KEY = "sk-ant-xxxx"
```

想让配置长期生效，就把上面这行追加到 `~/.bashrc` 或系统环境变量里。

## 四、跑第一个任务

进入那个空文件夹，启动工具，输入一句具体的话：

```text
在当前目录建一个 index.html，做一个只有标题和段落的静态页。
```

要点是**任务具体、范围小、结果可验证**。不要说"帮我做个网站"，那种需求模型只能猜。

跑完打开 `index.html`，浏览器里能看到页面，第一步就成了。

## 五、常见报错

| 报错 | 原因 | 处理 |
| --- | --- | --- |
| `command not found` | 安装没成功或没进 PATH | 重装，或把安装路径加进 PATH |
| `401 Unauthorized` | Key 错了或没读到 | 检查环境变量名有没有拼错 |
| `429 Too Many Requests` | 调用太频繁或额度用完 | 等几分钟重试，或去后台看余额 |
| 请求一直超时 | 网络到不了服务商 | 换网络，或配置代理 |

## 六、下一步

跑通之后可以试三件事：

1. 让它读你已有的项目，问"这个文件是干什么的"。
2. 让它改一个具体的小 bug，观察它怎么找问题。
3. 把重复的工作写成固定的提示词，存成文件反复用。

---

教程基于命令行版本编写，界面版操作路径不同但逻辑一致。
