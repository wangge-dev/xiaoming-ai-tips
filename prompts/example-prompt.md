# 通用提示词模板

一个结构化的提示词骨架，把「我要什么」说清楚，模型输出质量会稳定很多。

复制下面整段，替换方括号里的内容即可。

---

## 模板

```text
# 角色
你是一名[领域]专家，服务对象是[目标用户]。

# 任务
[一句话说清要产出什么，例如：写一篇 800 字的公众号推文]

# 背景
- 我的情况：[用户已知什么、缺什么]
- 已有素材：[粘贴资料，没有就写无]
- 使用场景：[产出之后用在哪]

# 要求
1. 结构：[开头/正文/结尾分别要什么]
2. 语气：[平实、口语、正式]
3. 篇幅：[字数或段落数]
4. 必须包含：[关键信息点]
5. 不要出现：[术语堆砌、空洞套话、编造的数据]

# 输出格式
[纯文本 / Markdown / 表格 / JSON，写明字段]

# 自检
产出前先检查：是否满足上面全部要求。若有做不到的，在结尾单独列出并说明原因。
```

## 变量说明

| 变量 | 填什么 | 常见错误 |
| --- | --- | --- |
| 角色 | 具体岗位 + 服务对象 | 只写"专家"，太泛 |
| 任务 | 一个动作 + 一个产出物 | 一句话塞三个任务 |
| 背景 | 已知信息、素材、用途 | 全空，模型只能瞎猜 |
| 要求 | 可验证的条件 | 写"写得好一点"这种没法判断的 |
| 输出格式 | 明确结构 | 不写，拿回来还要二次整理 |

## 示例

写一篇给新手看的 AI 工具入门推文：

```text
# 角色
你是一名科技类公众号作者，读者是刚接触 AI 工具的普通上班族。

# 任务
写一篇介绍 AI 对话工具能干什么的入门文章。

# 背景
- 我的情况：读者完全没用过，担心学不会
- 已有素材：无
- 使用场景：公众号推文，手机阅读为主

# 要求
1. 结构：开头直接说结论，中间三个使用场景，结尾一个当天就能做的动作
2. 语气：平实口语，不用专业术语
3. 篇幅：800 字左右，段落短，每段不超过四行
4. 必须包含：三个具体场景各举一个例子
5. 不要出现：夸张形容词、编造的数据、破折号

# 输出格式
Markdown，带小标题

# 自检
产出前检查是否满足全部要求，不满足的在结尾列出。
```

## 使用要点

- **背景不要省**。模型不知道你的情况，写得越具体，编造越少。
- **要求要能验证**。把"写得好"换成"每段不超过四行"，模型才知道怎么改。
- **加自检一句**。让模型先对照要求再交稿，返工次数明显下降。

---

适用模型：GPT-4o / Claude Sonnet / DeepSeek 等主流对话模型，2026 年实测有效。
